# 🎓 University Programming Exam Simulations (Java)

This repository contains a comprehensive collection of **Java programming exam simulations** and practical test exercises designed for university-level Computer Science and Computer Engineering courses. 

The goal of this project is to provide structured solutions to real or mock examination problems, demonstrating core Object-Oriented Programming (OOP) concepts, data structures, and algorithmic logic.

---

## 📌 Topics Covered

The solutions included in this repository address a wide range of fundamental and advanced Java concepts, including:

- **Object-Oriented Programming (OOP):** Encapsulation, Inheritance, Polymorphism, and Abstraction.
- **Data Structures & Collections:** Custom implementations and standard Java Framework collections (`List`, `Set`, `Map`, `Queue`, `Stack`).
- **Generics & Type Bounding:** Generic classes, methods, and wildcard constraints (`? extends T`, `? super T`).
- **Exception Handling:** Custom exception design and robust error-management strategies.
- **File I/O & Streams:** Reading, writing, and parsing text files/data formats.
- **Algorithmic Logic:** Array manipulation, search algorithms, sorting, and state-based logic.

---

## 📁 Repository Structure

Each exam simulation is organized in its own directory or package and includes:
- **Problem Statement / Specifications:** The context and requirements for the exam task.
- **Source Code (`/src`):** Clean, fully documented, and functional Java classes.
- **Test / Main Drivers:** Executable classes or unit test cases validating the expected behavior.

---

## 🛠️ Prerequisites & Setup

To compile and run the simulations in this repository, you will need:

1. **Java Development Kit (JDK):** Version 11 or higher (JDK 17/21 recommended).
2. **IDE (Optional):** NetBeans, VS Code or VS Codium.
