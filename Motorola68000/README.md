📟 3. Motorola 68000 Assembly (/Motorola68000)
Lower-level exercises focused on computer architecture, register manipulation, and execution flow:

Registers & Addressing: Data registers (D0-D7), Address registers (A0-A7), and immediate/direct/indirect addressing modes.

Assembly Control Flow: Subroutines, stack manipulation (MOVE, JSR, RTS), conditional branching (BNE, BEQ, BGT), and loop structures.

Data Operations: Arithmetic, logical shifts, bit manipulation, and array/matrix traversal at hardware level.
