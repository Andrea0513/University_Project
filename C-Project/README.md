⚡ 1. C Programming (/C_Project)
Focused on fundamental procedural concepts, manual memory control, and low-level system operations:

Memory Management: Pointers, dynamic allocation (malloc, calloc, realloc, free), pointer arithmetic.

Data Structures: Implementation of custom structs, single/doubly Linked Lists, Stacks, Queues, and Trees.

File I/O & System: Stream processing, binary files, dynamic strings, and modular programming (.h header files).
